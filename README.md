## Pasta `exemplos-origem`

Contém 15 códigos-fonte independentes em Python. Cada arquivo demonstra um ou mais conceitos da linguagem de origem:

| Arquivo | Conteúdo principal |
| --- | --- |
| `01_programacao_funcional.py` | Funções puras, funções de ordem superior, `map`, `filter` e `reduce` |
| `02_programacao_logica.py` | Fatos, regras, consultas e inferência |
| `03_orientacao_objetos.py` | Abstração, herança, encapsulamento e polimorfismo |
| `04_tipos_primitivos.py` | Tipos primitivos, conversões e números complexos |
| `05_tipos_compostos.py` | Classes de dados, enumerações, listas, tuplas, conjuntos e dicionários |
| `06_escopo_variaveis.py` | Escopos global, local e não local |
| `07_expressoes_operadores.py` | Expressões aritméticas, relacionais, lógicas e bit a bit |
| `08_fluxos_controle.py` | Condicionais, laços, entrada de dados e `match/case` |
| `09_subprogramas.py` | Parâmetros, argumentos variáveis, retornos e referências |
| `10_recursividade.py` | Funções recursivas e callbacks |
| `11_concorrencia_threads.py` | Threads, exclusão mútua e recurso compartilhado |
| `12_programacao_assincrona.py` | Corrotinas, `asyncio` e execução concorrente |
| `13_tratamento_excecoes.py` | Exceções personalizadas e blocos `try`/`except`/`finally` |
| `14_programacao_eventos.py` | Eventos, ouvintes e callbacks |
| `15_sistema_integrador.py` | Integração de orientação a objetos, eventos, expressões regulares e programação funcional |
